# Mobile Data Bundle Selector

A mobile data bundle calculator. The PHP application is in [`index.php`](./index.php), and a static HTML version is in [`index.html`](./index.html).

## Run the PHP application

GitHub stores the PHP source code but does not execute it. GitHub Pages only serves static files, so the live Pages site uses `index.html`, not `index.php`.

To run the PHP application locally, install PHP, open a terminal in this folder, and run:

```sh
php -S localhost:8000
```

Then open <http://localhost:8000/index.php>. To publish the PHP application online, deploy it to a web host that supports PHP.
